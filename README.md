# CIS11-Assembly-Programming-Project-

For this team project, I partnered up with my classmate Ashley Gallegos. We partnered up to 
create a project that would get the individual test scores of 5 students and be ran through
a program that would filter them into a min, max, and avg output. 

This program asks for user input, the use of different branching functions, and the use of 
store, load, and copy in order to achieve that goal. 

The implementation of this program is to showcase out understanding and learning of assembly
programming.
